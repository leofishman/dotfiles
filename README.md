# dotfiles

Personal config for a Linux dev laptop (Ubuntu, fish, Homebrew on Linux, Rust, Docker/ddev).

`home/` mirrors `$HOME`. `./install.sh` symlinks every file into place, so editing a
file in `$HOME` edits the repo copy. Existing real files are kept as `<file>.bak`.

```sh
git clone https://github.com/leofishman/dotfiles ~/Proyects/dotfiles
~/Proyects/dotfiles/install.sh
```

## What's inside

### Weekly disk cleanup

| File | Purpose |
|---|---|
| `bin/weekly-cleanup.sh` | The cleanup itself |
| `.config/systemd/user/weekly-cleanup.service` | Runs it at idle CPU/IO priority |
| `.config/systemd/user/weekly-cleanup.timer` | Sundays 11:00; `Persistent=true` catches up after the laptop was off |

What it removes:

- **Rust `target/` dirs** under `~/Proyects` (`$PROJECTS`) that saw no build in 14 days. Only
  dirs next to a `Cargo.toml`. Active projects are untouched; the cost of a removal is one
  full rebuild.
- **Package caches**: `uv cache prune`, npm, yarn, `brew cleanup --prune=30`.
  `~/.cache/solana` is deliberately left alone.
- **Docker**: images unused by any container for 30+ days, build cache older than 7 days,
  anonymous volumes. Named volumes (ddev databases) are never touched.

```sh
systemctl --user start weekly-cleanup     # run now
journalctl --user -u weekly-cleanup       # what it removed
systemctl --user list-timers weekly-cleanup.timer
```

### Rust

`.cargo/config.toml` sets `[profile.dev] debug = "line-tables-only"`: backtraces keep file
and line numbers, but `target/` shrinks a lot. Set `debug = true` in a project's
`Cargo.toml` when you need a debugger.

### fish

| File | Purpose |
|---|---|
| `.config/fish/config.fish` | PATH per platform (Linux / macOS / Termux), brew, zoxide, atuin, fzf (Ctrl+R only), carapace completions, abbreviations, color theme |
| `.config/fish/fish_plugins` | Plugins installed by [fisher](https://github.com/jorgebucaran/fisher) on first launch |
| `.config/fish/functions/fish_prompt.fish` | Minimal prompt: directory, git branch, ✗ on error |
| `.config/fish/functions/tmux.fish` | Forces 256 colors |
| `.config/fish/conf.d/fnm.fish` | fnm (Node version manager) init |

Not tracked on purpose: `fish_variables` (machine state, may hold secrets), fisher-managed
plugin files, and `completions/` (generated by carapace).

## Not here, on purpose

`~/.ssh/config`, tokens, `.env` files, anything with hostnames or credentials. This repo is
public.
